# Addon-Mikan — Telegram-бот подписчиков для панели Mikan

Аддон для панели [mikan](https://github.com/Miroshka000/mikan).

## Установка

1. В админке панели: **Аддоны → Источники → Добавить источник** → `github.com/Fortumers/Addon-Mikan`
2. Установить аддон, одобрить права.
3. Нажать «Отдать бота».

Нужна панель mikan 0.5.1.0+.
