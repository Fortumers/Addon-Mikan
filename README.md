# Бот подписчиков (Fortumers)

Аддон протокола 2 для панели Mikan 0.5.1.0 и новее. Это отдельная программа: меню в Telegram, автоответ и рассылка. Страница настроек открывается в админке панели.

Идентификатор: `fortumers-subs-bot`.

## Как поставить

1. В панели: **Аддоны → Источники**, адрес `github.com/Fortumers/Addon-Mikan`.
2. Обновите источник и установите **Бот подписчиков (Fortumers)**. Разрешения: бот, хранилище, страница в админке.
3. В настройках Telegram панели назначьте этот аддон ботом.
4. Откройте страницу аддона: приветствие, кнопки, автоответ, рассылка.
5. Человек пишет боту `/start` — после этого он попадает в список рассылки.

Образ публикуется в `ghcr.io/fortumers/addon-mikan` и прикрепляется к релизу файлом `mikan-addon.json` с digest. Панель ставит только такой файл.

Настройки и список чатов лежат в хранилище панели (kv), не в контейнере: контейнер только для чтения.
