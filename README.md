# Telegram‑бот подписчиков (Mikan‑addon)

## Описание

Это неофициальный аддон для **Mikan‑Panel** (версии 0.5.1.0+), реализующий отдельный Telegram‑бот, управляемый токеном панели. Бот умеет:

- отображать кастомное меню с «чип‑кнопками» (эмодзи, статус «выбран/отключён», цвет);
- работать в ночном беззвучном режиме (22:00‑09:00 МСК);
- сохранять настройки в хранилище аддона (включая список пользовательских кнопок);
- предоставлять UI‑страницу **«Кнопки статей»** в админке для CRUD‑операций над кнопками.

## Требования

- Go 1.22+ (модуль `go.mod` уже готов).
- Доступ к токену бота через переменную окружения `MIKAN_PANEL_BOT_TOKEN`, которую панель передаёт при «Отдать бота».
- SDK **Mikan‑Panel** (`github.com/mikan-panel/sdk`).

## Установка в Mikan‑Panel

1. **Создайте релиз** в GitHub, загрузив:
   - `mikan-subs-bot.dll`
   - `mikan-addon.json`
   - `index.json`
   - (по желанию) `README.md`
2. В панели перейдите **Аддоны → Источники → GitHub‑репозиторий → Установить**.
3. Выберите ваш релиз, нажмите **Установить**.
4. После установки нажмите **«Отдать бота»** – панель передаст токен боту.
5. Откройте страницу **«Кнопки статий»** в админке, чтобы управлять кнопками.

## Управление кнопками через UI‑страницу

- На странице отображается список кнопок в виде JSON‑массива.
- В реальном UI‑плагине (не включён в этом репозитории) будет использоваться `static/article_buttons.js` для CRUD‑операций.

## Добавление новых UI‑страниц

Создавайте новые файлы в каталоге `ui/` и регистрируйте их через `ui.RegisterPages()` в `addon/addon.go`.
